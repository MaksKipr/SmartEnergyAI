# SmartEnergy AI — нативное Android-приложение

Это **исходный Android Studio проект**, а не готовый APK. Приложение работает офлайн, использует встроенный ансамбль из 35 деревьев Random Forest, обученный на синтетических данных.

## Как собрать APK на Windows

1. Установите Android Studio с Android SDK (официальный сайт: https://developer.android.com/studio).
2. Распакуйте архив и откройте папку `SmartEnergyAI_Android` через **Open** в Android Studio.
3. Дождитесь Gradle Sync и установки необходимых компонентов SDK. Нужен интернет при первой сборке.
4. В меню выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Найдите APK по пути `app/build/outputs/apk/debug/app-debug.apk`.
6. Перенесите его на Android-телефон, разрешите установку из выбранного источника и установите.

Минимальная версия Android: 6.0 (API 23). Приложению не нужны разрешения на интернет.

## Для защиты

Покажите ввод площади, температуры, людей, рабочих часов, переключатель выходного дня, прогноз в кВт·ч и рекомендации. Объясните, что 35 деревьев обучены на 3500 синтетических примерах на компьютере и встроены в APK в виде JSON. На телефоне выполняется инференс (предсказание), а не обучение. Это учебная демонстрация, а не проверенная система учёта электроэнергии.
